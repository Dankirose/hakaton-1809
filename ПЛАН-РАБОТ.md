# План работ: демо на OpenDocuments (Docker + Ollama)

## Цель
Прототип интеллектуального ассистента по внутренним ЛНА на базе OpenDocuments (MIT).
Две задачи ТЗ: А) ситуационный поиск с цитатами и конфликтами норм; Б) выжимка по документу.
Весь запуск — через Docker. LLM и эмбеддинги — через хостовый Ollama.

## Принятые решения
- База: `joungminsung/OpenDocuments` (MIT).
- Лицензия: MIT (требование заказчика).
- LLM: `qwen3.5:cloud` (через хостовый Ollama).
- Эмбеддинги: `qwen3-embedding:0.6b` (1024 dims, хостовый Ollama).
- RAG-профиль: `balanced` (rerank + hallucination guard).
- Обращение контейнера к Ollama: `http://host.docker.internal:11434`.
- Порт демо: `3333` (порт 3000 занят open-webui).
- Старый проект `embedder/` удалён.

## Команды (всё через Docker)
```bash
cd hahaton/OpenDocuments-main

# поднять
docker compose -p smk-opendocuments up -d --build

# логи
docker logs -f smk-opendocuments-opendocuments-1

# переиндексировать документы
docker compose -p smk-opendocuments exec opendocuments \
  node packages/cli/dist/index.js index /demo-docs --reindex

# задать вопрос
docker compose -p smk-opendocuments exec opendocuments \
  node packages/cli/dist/index.js ask "Мне пришла повестка в суд на рабочий день — это оплачивается?"

# остановить
docker compose -p smk-opendocuments down
```

## Ограничения (честно для жюри)
